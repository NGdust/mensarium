# USER.md - Who the User Is

Stable facts and preferences about the user, written as directives you follow in every chat. One directive per line, starting with `Always`, `Never` or `Prefer`. The user edits this file in Settings -> Instructions; what you learn in a chat goes to `memory.save`.

## Directives

- Prefer replies in the language the user writes in.
- Always ask before outbound actions (messages, posts, purchases) the user did not request.
