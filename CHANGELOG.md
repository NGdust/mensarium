# Changelog

Версии по схеме `MAJOR.MINOR.PATCH`. Источник версии — `src/mensarium/__init__.py`, релиз помечается git-тегом `vX.Y.Z`.

## 0.11.0

- Агент устройства обновляется из web UI: в раскрытом устройстве кнопка «Обновить до …». Core отправляет подписанный запрос `target.update` (nonce, срок жизни, адресат), устройство проверяет его так же, как запросы на выполнение, скачивает версию со своего Core и перезапускается: сервис — через `mensarium update`, агент в foreground — сам. Пока идёт обновление, это видно в списке; в конце — уведомление.
- Владелец устройства может запретить удалённое обновление: `allow_remote_update` в конфиге target, вопрос в мастере, `mensarium target pair --no-remote-update`. Агенты до 0.11.0 обновляются один раз вручную (`mensarium update` на устройстве), UI подсказывает это.
- Core обновляется из «Обзора»: при новой версии на mensarium.com появляется кнопка «Обновить». Core запускает `mensarium update` в отдельном процессе и перезапускается, страница переподключается сама. Работает для установки через install.sh; копия из исходников обновляется через git.
- Запросы и результаты обновлений пишутся в журнал Core и в локальный журнал устройства.

## 0.10.0

- Память агента в настройках: заметки с типом, тегами, важностью и закреплением, связи через ссылки `[[Название]]`. При переименовании заметки ссылки на неё в других заметках обновляются. Секреты вычищаются при сохранении.
- Граф памяти в духе Obsidian: силовая раскладка на canvas, перетаскивание узлов, масштаб колесом и щипком, подсветка соседей, поиск узла. Клик открывает заметку с её текстом и обратными ссылками. Пустые узлы — ссылки на ещё не созданные заметки, теги показываются по желанию.
- Агент пользуется памятью: закреплённые и самые важные заметки попадают в системный промпт как данные, а не инструкции; инструменты `memory.search`, `memory.read`, `memory.save` выполняются в Core. `memory.save` только добавляет, чужой текст не переписывает. Профиль `coding-agent-v1` 1.2.0 включает память флагом `memory`.
- Сновидения по образцу OpenClaw. Лёгкий сон собирает новые чаты: реплики, ответы и сводки действий без вывода команд. В REM модель отбирает кандидатов с важностью, связями и темами. Глубокий сон закрепляет только прошедших порог: новые заметки, дополнение существующих или укрепление важности. Затем модель пишет запись в дневник.
- Сновидения запускаются каждую ночь в выбранный час (по умолчанию 03:00 по времени сервера Core) или кнопкой. Ночь без новых чатов пропускается. Пока агент спит, видна текущая фаза; дневник показывает статистику, темы и ссылки на изменённые заметки.

## 0.9.0

- Маркетплейс в настройках: каталог навыков и инструментов с поиском и фильтрами, карточка с описанием, командами и инструкцией, установка, обновление, включение и удаление. Свой пакет добавляется вставкой манифеста в YAML.
- Навык — инструкция для агента. В системном промпте только список включённых навыков, а текст агент загружает инструментом `skills.read`, который выполняется в самом Core.
- Инструмент из маркетплейса — шаблон одной команды с типизированными параметрами. Значения подставляются отдельными аргументами (значения с `-` в начале запрещены), команда уходит на устройство обычным подписанным `shell.exec` и проходит allowlist программ, классификацию риска и подтверждение.
- Инструменты из маркетплейса включаются и выключаются для каждого устройства в его панели; если нужной программы нет в списке разрешённых, это видно сразу.
- Каталог встроен в релиз и дополнительно загружается с `https://mensarium.com/dist/marketplace.json` (`marketplace.url` в конфиге Core); при недоступности сайта показываются встроенные пакеты.
- Профиль `coding-agent-v1` 1.1.0 разрешает установленные расширения (`allow_extensions`); профиль без этого флага их не видит.
- Списки в ответах агента и в инструкциях рисуются корректно: строки-продолжения и вложенные пункты больше не рвут нумерацию.

## 0.8.0

- Устройства в настройках раскрываются по клику: внутри переключатели инструментов агента, папки, список программ, состояние полного доступа и отзыв доступа.
- Выключенный инструмент Core не показывает модели и отклоняет политикой, даже если модель попробует его вызвать («инструмент выключен для этого устройства»). Настройка хранится в Core для каждого устройства, переключение пишется в журнал.
- Модели передаются только те инструменты, которые устройство реально поддерживает и которые для него включены; тот же список попадает в системный промпт.

## 0.7.0

- Модель выбирается прямо в поле ввода: кнопка с роботом и поиском по списку моделей провайдера, в новом и в открытом чате. Смена модели в чате действует со следующего шага агента, в ленте появляется отметка «Модель: …», запись идёт в журнал.
- Модель по умолчанию меняется в настройках кликом по модели из списка, без `mensarium setup`; Core сохраняет её в `config.yaml`.
- У модели иконка робота: в поле ввода, в настройках и в меню настроек.

## 0.6.0

- В настройках (Обзор) появился раздел «Резервная копия» с обеими командами: `mensarium core backup -o mensarium.pab` и `mensarium core restore mensarium.pab`, с пояснением, что делает восстановление.
- В архив `.pab` попадает встроенное устройство Core (`local-target`): после восстановления машина с Core остаётся тем же устройством, а не регистрируется заново.
- `mensarium core backup` в конце печатает команду восстановления для созданного файла.

## 0.5.0

- Полный доступ работает только там, где устройство его выполнит: агент версии 0.3.0 и новее и `allow_full_access` в его конфиге. Раньше Core на таких устройствах молча оставлял режим с запросом, а переключатель показывал «Полный доступ».
- Переключатель режима в новом и открытом чате показывает фактический режим выбранного устройства, а в меню объясняет, почему полный доступ недоступен: агент устарел или режим выключен на устройстве.
- Core отклоняет создание чата и смену режима на полный доступ для таких устройств с понятной ошибкой; в списке устройств — метка «полный доступ: обновите агент».

## 0.4.0

- Новый визуальный стиль админки: чёрная рамка, внутренняя панель со сливовой подсветкой, кнопки-таблетки, плоские фиолетовые кнопки без свечения, шрифт Onest (локально, с кириллицей), только тёмная тема.
- Лицо агента — живая сфера из частиц (canvas): вращается, волнуется и пульсирует, сильнее — когда агент думает; анимируются только видимые сферы, у ответов в ленте — статичный кадр; учитывается «уменьшить движение».
- Новый чат: сфера, шаблоны задач (подставляют текст), выбор устройства и режима в поле ввода.
- Убраны дубли: меню «Администратор», чип модели в поле ввода, устройство в поле ввода открытого чата, повторные статусы и версии в настройках; «Выйти» — в настройках.
- Сайдбар сворачивается; при скрытом сайдбаре в шапке есть кнопка нового чата.
- Причины отказов политики и статусы в журнале — по-русски; журнал показывает читаемые поля вместо JSON.

## 0.3.0

- Режимы доступа для каждого чата: «С запросом действий» и «Полный доступ» (всё без подтверждений, запрещены только привилегированные действия). Переключатель в поле ввода, смена режима пишется в журнал, при включении полного доступа висящий запрос одобряется сам.
- Полный доступ можно запретить на конкретном устройстве (`allow_full_access` в конфиге target, вопрос в мастере, `--no-full-access`); тогда Core продолжает спрашивать.
- Машина, на которой установлен Core, всегда доступна как устройство: встроенный агент регистрируется сам, без кода пары. Папки задаются в `local_target.roots` конфига Core и в мастере.
- В подписанный запрос на устройство добавлено поле `mode`; хеш политики совместим с устройствами прошлых версий.
- На мобильном меню закрывается тапом по фону.

## 0.2.2

- Свои сообщения показываются справа без подписи, ответы агента слева.
- Удаление чатов: из сайдбара и шапки чата, работающая задача сначала останавливается; запись в журнале действий сохраняется.
- Подтверждения остановки задачи и отзыва устройства — диалогом в стиле интерфейса.

## 0.2.1

- `mensarium update` перезапускает только сервисы, настроенные в текущей установке (`MENSARIUM_HOME`).

## 0.2.0

- Web UI в виде чата: сеансы по устройствам в сайдбаре, лента с ответами агента, карточками команд и подтверждениями, поле ввода с выбором устройства.
- Новая дизайн-система: тёмная тема с лавандовым акцентом, светлая тема, мобильная раскладка.
- Настройки отдельным экраном: обзор Core, модель, устройства с сопряжением по коду, профили, журнал действий.
- `mensarium update`: Core обновляется с mensarium.com, устройство — со своего Core; архив проверяется по sha256, сервисы перезапускаются.
- `mensarium version` показывает установленные роли и доступное обновление.
- Core отдаёт `/dist/latest.json`; UI помечает устройства со старой версией агента.

## 0.1.0

- Core: FastAPI, SQLite, цикл агента со state machine, approvals, аудит с цепочкой хешей.
- Target Agent: исходящее WebSocket-соединение, подписанные ED25519 запросы, nonce и срок жизни, allowlist программ и папок, вычистка секретов.
- LLM через OpenAI-совместимый API: Ollama Cloud, локальный Ollama, llama.cpp.
- Установка одним `install.sh` без Docker, мастер настройки, сопряжение по коду, сервисы launchd и systemd.
