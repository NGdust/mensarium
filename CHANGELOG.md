# Changelog

Версии по схеме `MAJOR.MINOR.PATCH`. Источник версии — `src/mensarium/__init__.py`, релиз помечается git-тегом `vX.Y.Z`.

## 0.2.2

- Свои сообщения показываются справа без подписи, ответы агента слева.
- Удаление чатов: из сайдбара и шапки чата, работающая задача сначала останавливается; запись в журнале действий сохраняется.
- Подтверждения остановки задачи и отзыва устройства — диалогом в стиле интерфейса.

## 0.2.1

- `mensarium update` перезапускает только сервисы, настроенные в текущей установке (`MENSARIUM_HOME`).

## 0.2.0

- Web UI в виде чата: сеансы по устройствам в сайдбаре, лента с ответами агента, карточками команд и подтверждениями, поле ввода с выбором устройства.
- Новая дизайн-система: тёмная тема с лавандовым акцентом, светлая тема, мобильная раскладка.
- Настройки отдельным экраном: обзор Core, модель, устройства с сопряжением по коду, профили, журнал действий.
- `mensarium update`: Core обновляется с mensarium.com, устройство — со своего Core; архив проверяется по sha256, сервисы перезапускаются.
- `mensarium version` показывает установленные роли и доступное обновление.
- Core отдаёт `/dist/latest.json`; UI помечает устройства со старой версией агента.

## 0.1.0

- Core: FastAPI, SQLite, цикл агента со state machine, approvals, аудит с цепочкой хешей.
- Target Agent: исходящее WebSocket-соединение, подписанные ED25519 запросы, nonce и срок жизни, allowlist программ и папок, вычистка секретов.
- LLM через OpenAI-совместимый API: Ollama Cloud, локальный Ollama, llama.cpp.
- Установка одним `install.sh` без Docker, мастер настройки, сопряжение по коду, сервисы launchd и systemd.
- Зашифрованный бэкап `.pab`.
