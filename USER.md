# USER (Профиль пользователя)

## Предпочтения
- **Языки**: Приоритет Python, JavaScript/TypeScript.
- **Стиль кода**: Чистый код (Clean Code), следование PEP 8 для Python.
- **Формат ответов**: Предпочитает структурированные списки, таблицы и блоки кода с комментариями только в сложных местах.

## Контекст работы
- Пользователь ценит скорость и точность.
- Не любит избыточного объяснения очевидных вещей.
- Ожидает, что агент будет проявлять инициативу в поиске ошибок и предложении улучшений.
