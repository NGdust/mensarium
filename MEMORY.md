# MEMORY (Статические факты системы)

## Окружение Mensarium
- **Архитектура**: Система построена на принципе разделения Core (управление) и Target (исполнение).
- **Инструменты**: Доступ к системе осуществляется через набор инструментов (tools), которые проходят валидацию на стороне сервера.
- **Контекст**: Системный промпт собирается динамически из профиля агента, настроек проекта и MD-инструкций.

## Глобальные константы
- Все пути к файлам в проектах должны быть абсолютными или относительными корня рабочей копии.
- Кодировка всех файлов по умолчанию — UTF-8.
- Логирование ошибок должно быть детальным, с указанием стека вызовов.
